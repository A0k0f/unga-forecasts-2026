# UNGA December 2026 sealed forecasts

Forecasts of UN General Assembly plenary votes, made before the votes took place, from resolution titles only. The model was trained on General Assembly votes from 1991 to December 2025.

The SHA-256 fingerprint in SEAL.txt covers sealed_forecasts_country.csv, sealed_forecasts_summary.json and sealed_forecasts_meta.json. These files will not be changed. Results will be added after the votes.
